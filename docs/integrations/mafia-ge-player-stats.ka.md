# მოთამაშის სტატისტიკის API — mafia.ge-სთვის

ეს დოკუმენტი განკუთვნილია **mafia.ge-ის (PHP) გუნდისთვის**.

ონლაინ მაფიის სერვერზე არსებობს ერთი ენდპოინთი, რომელიც აბრუნებს
მოთამაშეების სტატისტიკას. ერთ მოთხოვნაში შეგიძლიათ გადმოგვცეთ **რამდენიმე
`accountId` ერთდროულად** და მიიღოთ თითოეულისთვის ნათამაშები თამაშების
რაოდენობა.

ამჟამად ერთი მაჩვენებელია — `gamesPlayed`. მომავალში დაემატება სხვა
მაჩვენებლებიც (მოგებები, მოგების პროცენტი და ა.შ.), **ახალი ველების სახით** —
არსებული ველები არასდროს შეიცვლება და არ წაიშლება.

---

## 1. მისამართი და ავტორიზაცია

```
POST https://grand-hyena-805.eu-west-1.convex.site/api/stats/players
```

ჰედერები:

```
Content-Type: application/json
Authorization: Bearer <STATS_API_SECRET>
```

- ⚠️ **მისამართი ზუსტად ისე ჩაწერეთ, როგორც ზემოთ წერია.** ყურადღება მიაქციეთ
  ორ დეტალს:
  - დომენი არის `.convex.site` (და **არა** `.convex.cloud`);
  - მისამართში აუცილებლად უნდა იყოს `.eu-west-1` ნაწილი.

  თუ `eu-west-1`-ს გამოტოვებთ, სერვერი დაბრუნებს **ცარიელ `404`-ს ყოველგვარი
  შეტყობინების გარეშე** — ისე, თითქოს ენდპოინთი არ არსებობს. ეს ყველაზე
  ხშირი შეცდომაა, ამიტომ თუ `404` მიიღეთ, პირველ რიგში მისამართი შეამოწმეთ.
- `STATS_API_SECRET`-ს ცალკე, დახურული არხით მოგაწვდით.
- გასაღები **მხოლოდ სერვერზე** უნდა ინახებოდეს (მაგალითად `.env` ფაილში).
  არასდროს გადაიტანოთ ბრაუზერში ან JavaScript-ის კოდში — ვისაც ეს გასაღები
  აქვს, მას ყველა მოთამაშის სტატისტიკის წაკითხვა შეუძლია.
- მეთოდი არის `POST` (და არა `GET`), რადგან ID-ების სია გრძელი შეიძლება იყოს
  და URL-ში არ ჩაეტიოს.

## 2. მოთხოვნა

```json
{
  "accountIds": ["1024", "2048"]
}
```

`accountId` არის **იგივე ID, რომელიც მომხმარებელს mafia.ge-ზე აქვს**.

სამი დეტალი, რომელიც ცხოვრებას გიმარტივებთ:

1. **სტრიქონიც მუშაობს და რიცხვიც.** `[1024, 2048]` და `["1024", "2048"]`
   ერთი და იგივეა — `(string)` კასტი არსად გჭირდებათ.
2. **გამეორებული ID-ები ავტომატურად ერთიანდება.** `["7", 7, "7"]` ერთ
   ანგარიშად ითვლება.
3. **მაქსიმუმ 200 უნიკალური ID ერთ მოთხოვნაში.** თუ მეტი გაქვთ, დაყავით
   ნაწილებად (იხ. §6).

## 3. პასუხი

```json
{
  "stats": {
    "1024": { "gamesPlayed": 137 },
    "2048": { "gamesPlayed": 0 }
  },
  "missing": ["2048"]
}
```

| ველი | მნიშვნელობა |
| --- | --- |
| `stats` | ჩანაწერი **ყველა** მოთხოვნილი ID-სთვის, ID-ის მიხედვით დალაგებული |
| `gamesPlayed` | სულ რამდენი თამაში ითამაშა — **ორივე ვარიანტი ერთად** (იაპონური და სპორტული მაფია) |
| `missing` | იმ ID-ების სია, რომლებსაც ონლაინ მაფიაში ანგარიში საერთოდ არ აქვთ |

**მთავარი დეტალი:** `stats` ყოველთვის შეიცავს ჩანაწერს ყველა მოთხოვნილი
ID-სთვის — უცნობი ანგარიშისთვისაც კი, `0`-ით შევსებულს. ამიტომ
`$data['stats'][$id]['gamesPlayed']` ყოველთვის იმუშავებს და დამატებითი
შემოწმება არ გჭირდებათ.

`missing` მხოლოდ იმისთვისაა, რომ **განასხვავოთ ორი განსხვავებული შემთხვევა**:

- ID არის `missing`-ში → მომხმარებელი ონლაინ მაფიაში არასდროს შემოსულა.
- ID არ არის `missing`-ში, მაგრამ `gamesPlayed` არის `0` → შემოვიდა, მაგრამ
  ჯერ არცერთი თამაში არ დაუსრულებია.

თუ ეს განსხვავება თქვენთვის მნიშვნელოვანი არაა, `missing` უბრალოდ
იგნორირება გაუკეთეთ.

## 4. შეცდომები

ყველა შეცდომა ერთი და იმავე ფორმატით ბრუნდება, ამიტომ ერთი შემოწმება
გეყოფათ:

```json
{
  "error": "unauthorized",
  "message": "Invalid or missing bearer token."
}
```

| სტატუსი | `error` | მიზეზი და გამოსავალი |
| --- | --- | --- |
| `401` | `unauthorized` | გასაღები არასწორია ან საერთოდ არ გამოგზავნეთ. შეამოწმეთ `Authorization` ჰედერი. |
| `400` | `invalid_body` | JSON არასწორია, ან `accountIds` არ არის მასივი. |
| `413` | `too_many_accounts` | 200-ზე მეტი უნიკალური ID. დაყავით ნაწილებად. |

დაეყრდენით **`error` ველს**, და არა `message`-ს — `message` ადამიანისთვისაა
და შეიძლება შეიცვალოს.

## 5. PHP-ის მაგალითი (cURL)

```php
<?php

/**
 * აბრუნებს მასივს: [accountId => ნათამაშები თამაშების რაოდენობა]
 */
function fetchGamesPlayed(array $accountIds): array
{
    if (empty($accountIds)) {
        return [];
    }

    $url    = 'https://grand-hyena-805.eu-west-1.convex.site/api/stats/players';
    $secret = getenv('MAFIA_STATS_API_SECRET');

    $ch = curl_init($url);
    curl_setopt_array($ch, [
        CURLOPT_POST           => true,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT        => 5,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'Authorization: Bearer ' . $secret,
        ],
        CURLOPT_POSTFIELDS => json_encode([
            'accountIds' => array_values($accountIds),
        ]),
    ]);

    $body   = curl_exec($ch);
    $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    // ვერ დავუკავშირდით ან შეცდომა დაბრუნდა — გვერდი არ უნდა ჩავარდეს.
    if ($body === false || $status !== 200) {
        error_log("mafia stats API: status {$status}");
        return [];
    }

    $data = json_decode($body, true);

    $result = [];
    foreach ($data['stats'] ?? [] as $accountId => $stats) {
        $result[$accountId] = $stats['gamesPlayed'];
    }

    return $result;
}
```

გამოყენება:

```php
$games = fetchGamesPlayed([1024, 2048]);

echo $games[1024] ?? 0;   // 137
echo $games[2048] ?? 0;   // 0
```

## 6. 200-ზე მეტი ანგარიში

დაყავით 200-იან ნაწილებად და შეაერთეთ შედეგები:

```php
$allIds = [/* ... 1000 ID ... */];
$games  = [];

foreach (array_chunk($allIds, 200) as $chunk) {
    $games += fetchGamesPlayed($chunk);
}
```

## 7. Laravel-ის მაგალითი

თუ Laravel-ს იყენებთ, იგივე უფრო მოკლედ იწერება:

```php
use Illuminate\Support\Facades\Http;

$response = Http::withToken(config('services.mafia_stats.secret'))
    ->timeout(5)
    ->post(config('services.mafia_stats.url'), [
        'accountIds' => [1024, 2048],
    ]);

if (! $response->successful()) {
    return [];
}

$stats = $response->json('stats', []);

$gamesPlayed = $stats['1024']['gamesPlayed'] ?? 0;
```

`Http::withToken()` თავად ამატებს `Authorization: Bearer ...` ჰედერს.

## 8. რეკომენდაციები

- **დააკეშირეთ.** სტატისტიკა თამაშის დასრულებისას ახლდება — 5-10 წუთიანი
  ქეში სრულიად საკმარისია და ზედმეტ მოთხოვნებს მოგაშორებთ.
- **ერთი მოთხოვნა, მრავალი ID.** თუ გვერდზე 50 მოთამაშეა, გამოგვიგზავნეთ 50
  ID ერთ მოთხოვნაში — და არა 50 ცალკეული მოთხოვნა. გაზომილი დრო: 5 ID ≈ 0.54
  წამი, 200 ID ≈ 0.73 წამი — ანუ ID-ების რაოდენობა პასუხის დროზე თითქმის არ
  მოქმედებს, ცალკეული მოთხოვნების რაოდენობა კი — ძალიან.
- **დააყენეთ timeout** (5 წამი საკმარისია) და გაუძელით შეცდომას: თუ პასუხი ვერ
  მიიღეთ, აჩვენეთ ბოლო ცნობილი მნიშვნელობა ან უბრალოდ დამალეთ ბლოკი. ეს
  ენდპოინთი mafia.ge-ის გვერდის ჩავარდნის მიზეზი არ უნდა გახდეს.
- **მოემზადეთ ახალი ველებისთვის.** მომავალში `gamesPlayed`-ის გვერდით სხვა
  ველებიც გამოჩნდება. წაიკითხეთ მხოლოდ ის ველები, რომლებიც გჭირდებათ, და
  ნუ დაწერთ კოდს, რომელიც უცნობი ველის შემთხვევაში ჩავარდება.

## 9. სწრაფი შემოწმება

სანამ კოდს დაწერთ, ტერმინალიდან შეამოწმეთ:

```bash
curl -X POST 'https://grand-hyena-805.eu-west-1.convex.site/api/stats/players' \
  -H 'Authorization: Bearer <STATS_API_SECRET>' \
  -H 'Content-Type: application/json' \
  -d '{"accountIds":["1024","2048"]}'
```

მოსალოდნელი პასუხი:

```json
{"stats":{"1024":{"gamesPlayed":137},"2048":{"gamesPlayed":0}},"missing":["2048"]}
```

თუ სხვა რამ დაბრუნდა:

| რა მიიღეთ | რას ნიშნავს |
| --- | --- |
| `401` + `{"error":"unauthorized"}` | მისამართი სწორია, გასაღები არასწორია. |
| `404` **ცარიელი პასუხით** | მისამართი არასწორია — დიდი ალბათობით `eu-west-1` გამოტოვეთ. |
| `404` + `No matching routes found` | მისამართი სწორია, მაგრამ მეთოდი — არა. გამოიყენეთ `POST`, და არა `GET`. |
| `404` + ტექსტით `HTTP actions enabled` | მისამართი სწორია, მაგრამ ჩვენ ჯერ არ დაგვიდეპლოებია — მოგვწერეთ. |

სამივე შემთხვევა `404`-ია, მაგრამ პასუხის **ტექსტი** განსხვავებულია — სწორედ
ის მიგითითებთ პრობლემაზე.
